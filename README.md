# ☁️ CloudComplain

## Cloud-Based Complaint Management System

CloudComplain is a simple web-based complaint management system that allows users to submit, track, and manage complaints easily.

### ✨ Features

- 📊 Dashboard
- 📝 Submit Complaints
- 📋 View Complaints
- 🔎 Track Complaint Status
- 🗂️ Complaint Categories
- 🔔 Notifications
- 👤 User Profile
- 💾 LocalStorage Support

### 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
